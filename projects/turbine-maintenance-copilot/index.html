FILE / 04Method & boundaries

Decision support, never autopilot.

This repository is an engineering portfolio prototype inspired by maintenance workflows. It contains no confidential plant data.

  1. Synthetic only. Telemetry and procedure excerpts are authored for reproducible software tests.
  2. Illustrative thresholds. A rolling z-score baseline is a transparent starting point, not a calibrated failure model.
  3. Human in the loop. The output does not issue work orders, control equipment, or replace an authorized engineer.

Implementation

Python, pandas, typed response schemas, FastAPI, and focused tests.

Retrieval

Transparent lexical retrieval over authored evidence excerpts, with evidence IDs carried into the response.

Next validation
