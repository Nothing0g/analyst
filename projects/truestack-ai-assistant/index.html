FILE / 02System workflow

Route by request—not by guesswork.

FastAPI validates the request, then the central workflow selects the appropriate retrieval or tool path and returns structured output with trace information.

01 / RECEIVE

Validate the request

FastAPI endpoints use Pydantic request/response schemas. The workflow classifies the request before calling a component.

→
02 / ROUTE

Retrieve or calculate

Policy questions use document retrieval with source metadata. Student-specific questions use deterministic Python tools over SQLite records.

→
03 / RESPOND

Validate and audit

The response path preserves citations, response types, trace IDs, audit records, and explicit uncertainty or refusal when evidence is missing.

Retrieval

Sentence Transformers and ChromaDB are included for indexed document retrieval; source metadata and policy precedence matter alongside similarity.

Deterministic tools

SQLite-backed student, attendance, results, and eligibility scenarios keep calculations in code instead of asking a language model to invent numbers.

Local model path

When configured for real inference, local Qwen runs through Ollama. Mock mode is intended for pipeline smoke tests, not model-quality claims.

FILE / 05Boundaries & responsible use

A demo—not an official student service.

The project demonstrates routing, grounding, privacy checks, and auditable calculations. It is not connected to DTU’s live student systems and must not be used to make real academic decisions.

  1. Synthetic records. Student profiles, marks, and attendance scenarios are fictional demo data.
  2. Sample policies are labelled. Synthetic policy documents explicitly say they are not official DTU policy; real-source citations and synthetic examples must not be conflated.
  3. Human verification still matters. OCR-derived source text can contain errors. Verify the original document and cited page before relying on a clause.
  4. Local setup affects behavior. Actual model inference requires the configured local Qwen/Ollama setup; mock mode is for smoke testing.
