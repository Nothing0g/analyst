FILE / 03Readout

Three signals worth acting on.

The original write-up intentionally separates descriptive EDA from model performance and avoids pretending that a small HR sample proves causation.

01 / OVERTIME

Overtime is the strongest observed gap.

The original CSV gives 30.5% attrition among overtime employees versus 10.4% without overtime. The PDF recommends treating overtime as the primary retention lever.

02 / TENURE

The early-career window deserves focus.

The PDF reports median tenure of 3 years for leavers versus 6 years for stayers. That points toward targeted 0–3 year retention work rather than a broad company-wide intervention.

03 / EVALUATION

Recall changes the model decision.

Random Forest reaches 86% accuracy but 21% recall; Logistic Regression reaches 72% accuracy but 56% recall. For identifying actual leavers, the lower-accuracy model is more useful.

FILE / 04Retention recommendation

Turn the signal into a focused next test.

The data supports a practical sequence, not a definitive causal story.

  1. Audit overtime intensity and manager context. Treat overtime as the first investigation lever, then add schedule, workload, and manager notes that the current dataset does not contain.
  2. Design an early-career retention check. Focus the 0–3 year window with onboarding, manager check-ins, and exit-risk monitoring rather than spreading resources evenly across tenure.
  3. Use recall-first model evaluation. If a flagging tool is built, prioritize the leaver class and monitor precision/recall trade-offs instead of optimizing for accuracy alone.
FILE / 05Method & source

Dataset

Original `HR_Employee_Attrition.csv`: 1,470 employees and 35 source features covering demographics, compensation, satisfaction, and tenure.

Approach

Removed constant columns, checked nulls and duplicates, mapped the target, compared attrition rates by role/overtime/tenure, and used balanced Logistic Regression and Random Forest models.

Tools

Python · pandas · NumPy · Matplotlib · Seaborn · scikit-learn. The displayed population rates are recalculated from the original repository CSV.

Limitation

Attrition rates and feature importance show observed association within this sample. The original PDF notes that exit-interview text, manager notes, and engagement-survey data would be needed to explain why employees leave.
