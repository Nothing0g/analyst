# Shubham Kumar — Data, Software & AI Portfolio

**Live site:** https://nothing0g.github.io/analyst/

A personal portfolio showcasing projects across data analytics, data science, product thinking, software development, and applied AI. The visual direction uses a minimal monochrome interface and a numbered casefile motif; project reports describe the question, approach, evidence, and limitations.

## What's inside

- **Profile and experience:** education, internships, and relevant work.
- **Featured projects:** four selected case studies on the homepage.
- **Project archive:** nine case studies grouped across analytics, engineering AI, and product/design.
- **Detailed reports:** source-linked explanations, charts, workflow and methodology notes where appropriate.
- **Responsive interface:** light/dark themes, keyboard-accessible search, and reduced-motion/performance-lite behavior.

## Run locally

Because the site is static, no build step is required. From the repository root, run:

```bash
python -m http.server 8000
```

Then open http://localhost:8000/ in a browser. Opening the HTML file directly can behave differently for browser APIs and relative paths, so a local HTTP server is preferred.
